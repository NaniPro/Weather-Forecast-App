# Weather Forecast App

**Application web de prévisions météorologiques développée avec HTML, CSS et JavaScript.**

## Présentation

Ce projet est une application web permettant de rechercher une ville et d'afficher ses conditions météorologiques actuelles.

L'application utilise une API de géolocalisation pour obtenir les coordonnées géographiques d'une ville, puis récupère les données météorologiques correspondantes.

## Fonctionnalités

- Recherche météorologique par nom de ville.
- Géolocalisation d'une ville à partir de son nom.
- Affichage de la température.
- Affichage de la vitesse et de la direction du vent.
- Affichage de l'humidité relative.
- Affichage des conditions météorologiques.
- Affichage de l'heure des données météorologiques.

## Technologies utilisées

- HTML5
- CSS3
- JavaScript
- OpenWeather Geocoding API
- Open-Meteo API

## English

### Overview

A weather forecast web application built with HTML, CSS, and JavaScript.

Users can search for a city and retrieve its current weather conditions using geographical coordinates obtained through an external geocoding API.

### Technologies

- HTML5
- CSS3
- JavaScript
- OpenWeather Geocoding API
- Open-Meteo API

### Project Status

This project represents an early practical experiment with JavaScript, asynchronous API requests, external data retrieval, and DOM manipulation.
